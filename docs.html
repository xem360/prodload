What is Prodload?

Prodload is a modern, web-native sound queueing application built specifically for live theater, stage productions, broadcasts, and event sound engineering. By leveraging modern browser audio APIs and client-side ZIP packaging, Prodload allows sound engineers to organize, sequence, and trigger sound effects without server dependencies or complex installations.

💡 Zero Server Footprint: Prodload runs 100% locally inside your web browser. Audio files never leave your machine during show execution or file bundling.

Getting started

We recommend beginning with the Prodload Application. You can immediately drag and drop audio files (MP3, WAV, OGG, FLAC) into the cue builder to create your show order.

Check out the Quick Start Guide for a detailed walk-through on setting up hotkey triggers, creating standalone wait timers, and attaching stage script notes directly onto your cues.

Core capabilities

Prodload simplifies sound cueing during live performances with several dedicated workflows:

1. Sequential Spacebar GO Trigger: Fire your sound cues sequentially in order with zero latency using the spacebar key during live performances.

2. Standalone Wait Cues & Auto-Advance: Insert custom delay timers that automatically countdown and trigger the next sequential sound without manual operator intervention.

3. The .prodload Archive Format: Export your entire production into a single self-contained project archive containing audio binary blobs and JSON sequence configurations.

Running on Chromebooks

Prodload includes native detection and PWA support for ChromeOS devices, allowing sound technicians to install the system directly to their Chromebook desktop for full offline operation during stage rehearsals and performances.
